## What this repository changes

Commit `52bf9ff` is upstream's tree, byte-for-byte (modulo line endings). Everything
after it is this project's own work; `git diff 52bf9ff..HEAD -- config/ build.yaml` is
the complete set of modifications, and each file carries comments explaining the reason.

In summary: central role moved to the left half, sensor driver swapped to badjeff's
raw-input driver, trackball behaviour re-expressed as central-half input processors,
left display SPI declared on the board's actual pins, and the ZMK Studio snippet moved
to the left build.

## Two things to be aware of before redistributing

1. `tangbonze/zmk-config-Keyball61` and `badjeff/zmk-pmw3610-driver` publish **no
   licence file**. The `config/boards/shields/keyball61/` tree derives from the former,
   which in turn derives from the GPL-3.0 `Yowkees/keyball` project.
2. The vendor branch has moved on since `ce1e932` (`niceview` is at `f2d10605b3b6e5e7677a73f66fd879b6b69a9328`
   as of 2026-11-18). This repo is pinned to the older commit on purpose; see
   [docs/PROVENANCE.md](docs/PROVENANCE.md).
